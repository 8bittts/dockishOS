# Design System

Marks, materials, motion and accessibility contracts for the DockishOS bar, launcher, switcher and Settings.

## Marks

- The app icon asset is a full-bleed square generated by `scripts/generate-app-icon.swift`; macOS applies the icon mask.
- The menu-bar extra is a template silhouette of the DockishOS mark from `DockishBrandAssets`, so it tints with the menu bar.
- `scripts/generate-dmg-background.swift` renders the DMG background.
- `build/dockishos.png` is the README mark, `public/dockishos-bar-preview.png` the product preview, and `build/yen.png` the YEN credit image; `.gitignore` re-includes the two `build/` images because the README embeds them.

## Materials and color

The bar, launcher and switcher HUDs use the system material, and switch to an opaque window material when Reduce Transparency is on.
Notification badges use system red.
The collapsed edge tab uses the window background and separator colors.

## Motion

Collapse and expand slide, and skip the slide when Reduce Motion is on.

## Accessibility

The bar can become the key window so VoiceOver and Full Keyboard Access reach the chips, without activating the app on mouse clicks.
Settings pinned-list reorder and unpin controls meet the 20-point minimum hit target and carry VoiceOver labels.
The bar, launcher and switcher panels carry spoken titles, the launcher search field keeps its name after text is typed, and each Settings Reset button names the row it clears.
A badge of one reads as "notification" and a single grouped window as "window".
`Tests/DockishOSCoreTests/HIGAccessibilityRegressionTests.swift` guards the key-window, Space-command, Reduce Motion, Reduce Transparency and usage-description contracts ([09-quality.md](09-quality.md)); the spoken names have no regression test.
